ELEN — исправленная статическая версия сайта

ЗАПУСК
1. Распакуйте архив полностью в отдельную папку.
2. Откройте index.html двойным щелчком в браузере.
3. Для локального сервера (рекомендуется): откройте терминал в папке elen и выполните: python -m http.server 8000
   Затем откройте http://localhost:8000

ЧТО ИСПРАВЛЕНО
- Удалены ссылки на отсутствующие/неверные файлы, в которых вместо JavaScript был HTML с ошибкой 404.
- Удалены старые ссылки на Cloudflare email decoder и Google Maps API с встроенным ключом.
- Добавлена проверка обязательных полей контактной формы и корректности email.
- Добавлены инструкции и отчёт проверки ссылок.

ВАЖНО
Это статический HTML-шаблон. Форма сейчас проверяет данные в браузере, но не отправляет письмо автоматически. Чтобы включить отправку, укажите настоящий адрес владельца сайта в CONTACT_EMAIL в js/site-fixes.js; тогда форма откроет почтовую программу пользователя с подготовленным письмом. Для отправки без почтовой программы нужен сервер/API формы.
Адреса, телефон, соцсети, текстовые ссылки и местоположение в исходном шаблоне могут быть демонстрационными — замените их своими. Без ваших данных нельзя достоверно настроить контакты.
